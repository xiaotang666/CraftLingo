目标语言：<target_language>

请严格按以下规范完成翻译，并按下文「待翻译文件格式」返回结果。

────────────────────────────────────────
一、翻译规范
────────────────────────────────────────
1. 语义层：消除机翻感
意译优先、直译慎用，拒绝逐词堆砌。

原文	劣质翻译	推荐译文
The Red Cedar Tree is a large tree that has magical properties.	红柏树是一棵有魔法属性的大树。	高大无比的红柏树有着魔法的属性。
Entity is not valid for placement here	实体在此处放置无效	此处无法放置该对象
翻译前先了解模组背景、物品功能、界面布局，理解词条在语境中的含义；
生造词根据游戏内表现和词根拟译，无特殊含义可音译；
技术术语玩家友好化：tick→刻（首次加注"20刻=1秒"）、chunk→区块、render distance→视距。
2. 交互层：UI 空间与操作直觉
长度控制 ✅：按钮/标签/提示语严格控制在原字符串 ±15% 长度内（Linter 对 ≤40 字符短文本告警）；
标点与空格 ✅：优先半角标点节省像素空间；菜单项无空格连接（"世界生成设置"）；中英文之间加空格；
动词一致性：操作按钮统一"动词+宾语"（"创建世界"/"导入存档"/"打开日志"，不要"开始创建"）；
格式代码与占位符保护 ✅（错误级）：
类型	示例	要求
格式码	§a、&l	必须保留在对应文本两侧
顺序占位符	%s、%d	可调换顺序（%2$d），数量必须一致
命名占位符	{0}、%msg%	完整保留
换行符	<br>、\n	保留
tellraw JSON	{"text":"..."}	仅翻译 "text" 值
3. 文化层：黑话与彩蛋
机制黑话转译：AFK→挂机、Chunk loader→（生存服）常驻区块器、Redstone contraption→红石机关；
彩蛋可二次创作植入中文梗，但必须标注"创意译文"并保留原文对照；
遵循 Minecraft 标准译名（zh.minecraft.wiki），除非与模组语境/代码冲突。自动拦截低质网络用语（脑残/傻逼/尼玛等）请按照这个要求进行翻译  结果以zh_cn.json的格式导出 如果不知道什么格式请去mc拥有这种格式的mod仓库源码中查看不要自己猜导致识别出错

────────────────────────────────────────
二、AI 生成标注要求
────────────────────────────────────────
1. 由 AI 生成或 AI 润色的译文属于 AI 生成内容，必须在条目上注明「AI 生成」，方便后续人工复核与修改。
2. 本工具在生成资源包时，会自动为 AI 翻译的条目追加 `.__ai_note` 注释键，例如：
   "block.redcedar.red_cedar_log": "红柏木原木",
   "block.redcedar.red_cedar_log.__ai_note": "AI 生成 | 原文: Red Cedar Log | 建议人工复核"
   该注释键不会被游戏引用，不影响游戏内文本显示。
3. 本次外部翻译请在每条译文的 `targetText` 中只填写纯译文，不要把「AI 生成」等注释写进译文本身，也不要自行添加 `.__ai_note` 条目；标注由工具导入后统一处理。
4. 如果某条译文属于创意译法、低置信度或需要特别说明，请在最终回复的文字中单独列出，不要写入译文。

────────────────────────────────────────
三、待翻译文件格式说明与实例
────────────────────────────────────────
待翻译文件是一个 JSON，包含 schemaVersion、jobId、targetLanguage、entries 四个字段。
你只需要把 entries 中每个对象的 targetText 填成目标语言，其余字段（entryId、modId、sourceFile、key、sourceText）必须保持原样：
- 不得增删条目；
- 不得修改 entryId；
- 不得改动占位符、格式码的位置与数量。
本次以上述 JSON 结构为准，无需另外输出 zh_cn.json。

完整实例（节选，实际以文件中的条目为准）：
{
  "schemaVersion": 1,
  "jobId": "translate-20261125-120000",
  "targetLanguage": "<target_language>",
  "entries": [
    {
      "entryId": "1f0c9a2b7d",
      "modId": "redcedar",
      "sourceFile": "assets/redcedar/lang/en_us.json",
      "key": "block.redcedar.red_cedar_log",
      "sourceText": "Red Cedar Log",
      "targetText": "红柏木原木"
    },
    {
      "entryId": "8b3e4c5d6a",
      "modId": "redcedar",
      "sourceFile": "assets/redcedar/lang/en_us.json",
      "key": "item.redcedar.magic_wand",
      "sourceText": "Magic Wand",
      "targetText": "魔法杖"
    }
  ]
}

返回时请保持同样的 JSON 结构，把填好的完整内容一并给出，方便直接导入回 CraftLingo。
